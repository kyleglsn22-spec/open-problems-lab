# Sra's quantum coupon-collector conjecture

## Statement
For symmetric positive definite `X₁, …, Xₙ ∈ S^d_{++}`, let
`Qₙ = ∑_{k=1}^n (-1)^{k+1} ∑_{i₁<⋯<i_k} (X_{i₁} + ⋯ + X_{i_k})^{-1}`, the matrix analogue of the
coupon collector's expected waiting time. Conjecture (Sra, MathOverflow 263833): `Qₙ ≻ 0` for every `n ≥ 1`.

| True for `n ≤ 5` (facet-averaging argument) | 2608.29595 | No |
| False for `n = 6`, `d = 3`: `Xᵢ = wᵢ uᵢuᵢᵀ + I/100`, `v = (4,1,3)` gives `vᵀQ₆v ∈ (−96, −95)` | 2608.29595 | Yes (QC-1) |
| Even `tr Qₙ > 0` fails (`n = 10`, moment-curve matrices) | 2608.29595 | No |

Statement notes for the Auditor:
- `couponMatrix X` sums over nonempty `S ⊆ Fin n` the matrix `(-1)^(|S|+1) • (∑_{i∈S} Xᵢ)⁻¹`, with Mathlib's
  `Matrix.inv` (the nonsingular inverse). Every subset sum here is positive definite, so `⁻¹` is the true inverse.
- `Matrix.PosDef` over `ℝ` means symmetric and `xᵀMx > 0` for `x ≠ 0`, i.e. `S^d_{++}` and `≻ 0`.
- `SraConjecture` is quantified exactly as posed: all sizes `d`, all `n ≥ 1`.
- Proof route: `sol S` is a rational vector with `X_S · sol S = v` (kernel-checked for all 63 nonempty `S`, data
  generated by `explorer/quantum-coupon/genlean.py`, untrusted), hence `X_S⁻¹ v = sol S`; then
  `vᵀQ₆v = ∑ ±(v ⬝ sol S)` is a rational number, kernel-checked to be negative.
