# Slow Fibonacci walks: the gap-set conjecture

## Statement
Chung, Graham and Spiro (slow Fibonacci walks) showed that every `n ≥ 2` has a unique representation
`n = a f_t + b f_{t-1}` with `t ≥ 2`, `1 ≤ a ≤ b ≤ f_t`, and that `n` is a *down-integer* (the slow walk to `n`
continues with `⌊φn⌋`) iff `t` is even, an *up-integer* (it continues with `⌈φn⌉`) iff `t` is odd. With
`d_1 < d_2 < ⋯` the down-integers and `u_1 < u_2 < ⋯` the up-integers, the `ℓ`-step gap sets are
`D_ℓ = {d_{k+ℓ} − d_k}` and `U_ℓ = {u_{k+ℓ} − u_k}`. They proved `D_1 = U_1 = {1,2,3,5}` and
`D_2 = U_2 = {2,3,4,5,6,8,10}` and conjectured `D_ℓ = U_ℓ` for every `ℓ ≥ 1`.

Statement notes for the Auditor:
- `IsRep n t a b := 2 ≤ t ∧ 1 ≤ a ∧ a ≤ b ∧ b ≤ fib t ∧ n = a * fib t + b * fib (t - 1)` (Mathlib's `fib` has
  `fib 1 = fib 2 = 1`, the paper's `f_1 = f_2 = 1`). `IsDown n := ∃ t a b, IsRep n t a b ∧ Even t`, `IsUp` with
  `Odd t`. This is the CGS characterisation, which Aliabadi also uses as his working definition; we do not
  formalize slow walks themselves. Every `n ≥ 2` is down or up (`exists_rep`, our proof: take `t` maximal, then `b`
  minimal). We do not prove uniqueness (that no `n` is both); no step of the proof needs it, but the definitions agree with
  CGS's D and U by their uniqueness theorem (the Auditor also brute-forced uniqueness for all `n < 20000`), and the finite facts about `U` used
  for `9 ∈ U_4` are computed exactly.
- `gapSet p ℓ = {nth p (k + ℓ) − nth p k | k}` with Mathlib's `Nat.nth` (0-indexed, so `nth p 0 = d_1`). Both sets
  are infinite (`down_infinite`, `up_infinite`: `f_{t+1}` has representation `(1, 1, t)`), so `nth` is the
  increasing enumeration.
- `δ n = Int.fract (φ * n)`, `ρ = (2+φ)/5 = 1 − 1/(√5φ)`, `η = (3−φ)/5 = 1/(√5φ)`, matching the paper's `η`, `ρ`.
- Shift lemma (`shift`): for even `t ≥ j + 1`, `j ≥ 2`, and `θ` with `θ√5φ^{j−1} = φ^{j−2} + 1`, a down-integer
  with `δ ≥ θ` moves by `(−1)^{t−j} f_j` to another down-integer (new representation `(a + f_r, b − f_{r+1})`,
  `t = r + j + 1`, d'Ocagne identity `fib_shift_identity`). The thresholds `θ₂ … θ₆` are exact values in `ℚ(φ)`.
- Case analysis (`core`): `x = δ n` is split into the 10 intervals on which each `δ(n+j) = {x + jφ}` is linear, then
  all `2^8` membership patterns of `n+1, …, n+8`; `linarith` closes every case (`maxHeartbeats` raised for this one
  theorem; it takes about 4 minutes to elaborate). Windows with `n ≤ 104` are checked by `decide` on a Boolean
  description `downB` proved correct below 377.
- Standard axioms only; no `native_decide`.

## Dead ends and notes
- Without `D_1`, `D_2` (CGS), Aliabadi's two shifts leave 9 of the 56 patterns open; three more shifts
  (`+1, −2, +3`) close them all.
- `D_3 = U_3` is not open: Mao–Zhao (2608.19886) proved it before Aliabadi's paper appeared. Still open: for which `ℓ`
  is `D_ℓ = U_ℓ`, and does it fail for infinitely many `ℓ`? FW-3 adds `ℓ = 7`, FW-4 adds `ℓ = 8, 9`.
  Certified computations add more values up to `ℓ = 24`, and plain computation finds a difference for every `ℓ` from
  15 to 300.
- Attempt at infinitely many `ℓ` (2026-11-28, parked): see `explorer/fib-walk/valleys.md`. Exact per-family rule (each
  CGS family is a moving interval of `{φn}`). Heuristic, checked numerically only: `n` is down iff `{φn} < c(n)` for a
  cut `c(n)` that is piecewise linear and oscillates between `η` and `ρ`. Differences come from
  the valleys `n = f_t f_{t+1}`, where down-valleys and up-valleys have mirror-image (not equal) shapes, and valley `t`
  first contributes at `ℓ ≈ f_t`. Turning this into a proof needs a renormalization argument plus a uniform exclusion
  over all straight-cut windows; not done.
- FW-2 notes. The constraints we use are mirror-symmetric: reversing the window, swapping down ↔ up and `δ ↔ 1 − δ`
  maps the down constraints to the up constraints. So for `n ≥ 105` every window ruled out for `D` is also ruled out
  for `U`. Differences between `D_ℓ` and `U_ℓ` can only come from small `n`, or from windows the constraints fail to
  rule out. This matches `9 ∈ U_4`, which occurs only at `u = 8`. For `ℓ = 3` the constraints (shifts `f_2..f_6`) rule
  out exactly the gaps `9, 12, 14, 15`, plus every gap `≥ 6` between consecutive members.

Statement notes for FW-2:
- Same definitions as FW-1 (`IsDown`, `IsUp`, `gapSet` with `Nat.nth`). `gapSet_three` states both set equalities.
- Up-integer shift (`shift_up`): for odd `t`, `(1 − δ n) φ^t = φ b − a`. So an up-integer with `1 − δ ≥ θ_j` moves by
  `(−1)^{t−j} f_j = −(−1)^j f_j` to another up-integer. The wrappers `up_minus1`, `up_plus2`, `up_minus3`,
  `up_plus5`, `up_minus8` need `N ≥ 41`, which forces `t ≥ 7`.
- Each window lemma `pat_T_*` uses only facts about `T` (the type of its members), so it never needs "not both down
  and up".
